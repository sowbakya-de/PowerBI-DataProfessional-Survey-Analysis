# Data Professional Survey - Power BI Project

An end-to-end Power BI projectt analyzes a dataset from a global survey of data professionals. It provides insights into job satisfaction, challenges in entering the data field, remote work preferences, demographics, and more.

## Project Overview

- **Tool used:** Microsoft Power BI
- **Data source:** Excel survey dataset (`Excel Data Set - Data_Professional_Survey_Analysis.xlsx`)
- **Skills showcased:**
  - Data cleaning and transformation
  - DAX calculations
  - Visual storytelling using charts, slicers, and filters
  - KPI design for satisfaction metrics

## Key Insights
- Common career satisfaction trends (management, learning, growth)
- How hard it is to break into data roles
- Preferences for remote work, salary, or work-life balance
- Distribution by gender, age, country, education

## Files Included
- Excel Dataset (Excel Data Set - Data_Professional_Survey)
- Power BI Report (PowerBI - Data_Professional_Survey_Analysis)
- Dashboard Screenshot (Screenshot.png)

## Project Steps

1. **Data Cleaning**: Removed nulls, standardized columns, handled duplicates in Excel and Power Query.
2. **Data Modeling**: Created a star schema model with relationships between fact and dimension tables.
3. **DAX Measures**: Created custom measures like Total Revenue, Profit Margin, YoY Growth, and Customer Count.
4. **Dashboard Design**: Used cards, bar charts, pie charts, slicers, and matrix visuals for interactivity and clarity.
